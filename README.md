# Vehicly AI Releases

Repositorio público de distribución de **Vehicly AI**.

Este repositorio contiene únicamente APK compiladas y archivos de actualización. **El código fuente de Vehicly AI no se publica acá** y permanece separado en un repositorio privado.

## Descargas y actualizaciones

Las versiones oficiales se publican en **GitHub Releases** como `Vehicly-AI.apk`.

La aplicación consulta `latest.json` para detectar nuevas versiones. Ese archivo contiene la versión, el enlace directo a la APK y su SHA-256.

> Todas las versiones oficiales conservan el package `ar.com.vehicly.ai` y la misma firma estable para poder instalar una actualización encima de la anterior sin borrar los datos locales.
